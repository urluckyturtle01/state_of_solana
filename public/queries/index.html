Hotspot Get

Lookup by any identity: hotspot_key, entity_key, entity_key_b64, asset_id, or key_to_asset_key. Animal name is not in this table; the API enriches it from entities.nft.helium.io using the entity key.

Endpoint
GET /api/helium/hotspot/hotspot_get
Parameters
address Required string

Hotspot / gateway signing pubkey (base58).

You must include this in every request.

Response schema
FieldTypeDescription
addressvariesHotspot / gateway signing pubkey (base58).
assetIdvariesCompressed-NFT asset address for the hotspot entity.
entityKeyvariesCanonical Helium Entity Manager entity identifier (bytes).
entityKeyB64variesEntity key, base64-encoded for oracle JSON transport.
keyToAssetKeyvariesHEM PDA linking entity + DAO to on-chain asset_id (cNFT).
keySerializationvariesEntity key encoding for hashing (e.g. b58, utf8).
daovariesDAO scope: IoT or Mobile rewards namespace.
mintDatevariesEntity / cNFT mint timestamp.
Request
Sample response
